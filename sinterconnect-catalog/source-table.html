TSV_Local

Original context
Original user case: photographs converted to CMD by OCR and manually corrected; the user confirmed the original-version identity.
Original input
D:/WORK/qx_deck/SI/tsv_stress/cmd_flat/; cmd/ contains categorized copies; ocr_clean/photo_to_cmd_manifest.csv traces photographs to CMD files.
Adaptation
The OCR-converted directory is the original input. The repository integrates a mesh-simplified version. cmd_flat and cmd organize the same inputs differently; they are not the original and simplified versions.
Notes
The original verify_in_vm.sh performs vendor syntax checks only: 28 expanded files plus one expanded template. The user confirmed integration of the simplified version; repository paths, verification entry point and current results remain to be checked.

Package_Reliability

Original context
Backend / Package_ThermomechanicalReliability; archived as a PowerSO-10RF / LDMOS adaptation.
Original input
benchmark-golden/original-case/dpack_struct_sis.cmd
Adaptation
Geometry, materials and solution flow were adapted. The benchmark separates thermal and mechanical solution entry points.
Notes
The two solution CMD files run sequentially. Geometry generation is an additional prerequisite. Four-step mechanics, 400 K, initial-temperature and parameter-error checks are variants of this case.

Submodeling

Original context
Adapted from part of an existing case (confirmed by user); the exact parent-case mapping remains to be checked.
Original input
Candidate source: original/submodel-candidates/PackageAssembly_Stress/*; vendor-original.cmd is also archived, but this does not establish direct derivation.
Adaptation
The workflow targets global displacement mapping onto a refined single-pillar mesh. It is an adaptation, not an independently invented case.
Notes
The two solution CMD files have a data dependency. Frozen-mesh variants are global-freeze.cmd / unit-fine-freeze.cmd. Temperature is a prescribed cooling load, not a heat-conduction solution.

Quasistatic

Original context
Purpose-built feature case (confirmed by user), with no direct external reference case.
Original input
Purpose-built baseline; the archived vendor-reference-cantilever.cmd is a separately retained reference, without a confirmed derivation relationship.
Adaptation
The same model produces 16 frames with different loads. These form one case series, not 16 independent features.
Notes
The 16 CMD files are parameter variants, not a sequential 01→16 result chain. An arch-quasistatic variant is also retained.
