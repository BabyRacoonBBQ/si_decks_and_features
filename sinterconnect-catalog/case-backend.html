Backend_Package_Reliability

Backend / Package reliability

Status
Needs review
Mode
mode thermal; mode mechanics
Device
Power semiconductor package, adapted from a PowerSO-10RF / LDMOS device package.
Case background
Uneven heating causes differential thermal expansion between package materials, producing thermomechanical stress. The temperature field is mapped into the mechanical calculation.
Configuration
Geometry, materials and solution flow were adapted. The benchmark separates thermal and mechanical solution entry points.
Capabilities
Steady-state heat transfer · conduction / convection / radiation · thermal expansion · thermal stress
Execution flow
Geometry / mesh.tdr → thermal_bench.cmd → temperature output → mechanics_bench.cmd
Execution notes
The two solution CMD files run sequentially. Geometry generation is an additional prerequisite. Four-step mechanics, 400 K, initial-temperature and parameter-error checks are variants of this case.
Commands
  1. benchmark-golden/package/thermal_bench.cmd
  2. benchmark-golden/package/mechanics_bench.cmd
